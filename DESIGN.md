## Brand & Style

This design system expresses the discipline, cutting-edge technical depth, and cinematic poise of an AI researcher and software architect. It moves deliberately away from chaotic, hyperactive "cyberpunk" tropes and juvenile gamer neon. Instead, it embodies a quiet, high-voltage minimalism—recalling high-precision laboratory consoles, cinematic sci-fi interfaces, and computational luxury.

### Target Audience & Persona
- **Audience:** Leading AI research labs, frontier tech recruiters, venture engineers, and senior technology directors seeking elite engineering talent.
- **Impression:** Intellectually rigorous, technically precise, avant-garde, and meticulously composed.

### Aesthetic Methodology
- **Cinematic Dark Field:** Deep, non-flat dark canvas tones rooted in near-black charcoal with subterranean navy undertones create boundless atmospheric depth.
- **Controlled Spectral Light:** High-frequency electric purple and cyan are strictly deployed as luminous data signatures, focal borders, and low-opacity atmospheric glows, never flat decorative floods.
- **Precision Glassmorphism:** Translucent glass plates with tight frosted diffusions, ultra-fine microscopic border strokes (1px), and spectral edge reflections.
- **Architectonic Typography:** Expressive geometric tension in display headings balanced against pristine, utilitarian body text and monospaced diagnostic notation.

## Colors

The palette establishes visual drama through extreme dynamic range: obsidian-deep voids punctuated by controlled photon emissions.

### Core Architecture
- **Canvas Base (`#090A0F`):** Deep charcoal void with absolute zero luminosity in structural recesses.
- **Surface Layer 1 (`#0D111A`):** Deep navy-charcoal for primary structural scaffolding, panels, and large-format module backdrops.
- **Surface Layer 2 (`#141926`):** Raised interactive surface for cards, code sandboxes, and elevated modals.
- **Surface Layer 3 (`#1D2436`):** Hover states, elevated active toggles, and floating menu nodes.

### Accent & Emission Palette
- **Electric Violet (`#8B5CF6` / `#A78BFA`):** Primary focal token; designates primary actions, generative compute states, model weight indicators, and interactive boundaries.
- **Soft Violet (`#C084FC`):** Tertiary gradient step, micro-badges, and refined visual highlights.
- **Subtle Cyan (`#38BDF8` / `#06B6D4`):** Secondary precision token; indicates model inference, operational latency, algorithmic benchmarks, and live telemetry.
- **Deep Glow Field (`rgba(139, 92, 246, 0.08)` to `rgba(56, 189, 248, 0.05)`): Ambient radial blur sources for background luminance.

### Text & Line Contrast
- **High-Contrast Text (`#F8FAFC`):** 96% luminance slate-white for headlines and critical interactive labels.
- **Muted Narrative Text (`#94A3B8`):** Low-strain, neutral slate for research descriptions and long-form prose.
- **Subdued Trace (`#475569`):** Metadata, line counters, and inactive indicators.
- **Micro-Borders (`rgba(255, 255, 255, 0.08)`): Base component perimeter; ascends to `rgba(139, 92, 246, 0.35)` on hover or focus.

## Typography

The typography creates a sharp dialectic between human conceptual curiosity and mechanical precision.

### Hierarchy & Pairing
- **Space Grotesk (Display & Headlines):** Used for titles, section anchors, and statement metrics. It conveys structural engineering prowess with slight geometric eccentricities.
- **Inter (Body Copy & Longform):** Delivers transparent, frictionless legibility across all viewport conditions, providing balanced contrast against expressive display headlines.
- **JetBrains Mono (System Labels & Metas):** Handles telemetry metrics, parameters, code excerpts, timestamps, and architectural metadata tags. Always rendered with relaxed letter spacing (`0.06em` - `0.12em`) and upper-case casing where applied to UI badges.

### Typographic Restraint
- Never use full-spectrum neon styling on headline fonts; prioritize clean slate-white typography (`#F8FAFC`).
- Reserve dynamic gradient fills (Electric Purple to Subtle Cyan) strictly for micro-accent text, key display phrases (1-3 words max), or numerical statistical achievements.

## Layout & Spacing

The layout philosophy is defined by generous, intentional negative space—a cinematic presentation style that lets complex machine learning projects breathe.

### Grid Architecture
- **Desktop (>= 1280px):** 12-column fluid grid contained within a maximum canvas width of `1360px`. Gutter spacing: `2.5rem`. Margin spacing: `5rem`.
- **Tablet (768px - 1279px):** 8-column fluid grid. Gutter spacing: `1.5rem`. Margin spacing: `2.5rem`.
- **Mobile (< 768px):** 4-column fluid layout with dynamic full-width edge wrapping. Gutter spacing: `1rem`. Margin spacing: `1.25rem`.

### Spatial Rhythm
- **Macro Spacing:** Project showcases, academic paper breakdowns, and interactive demonstrations are demarcated with `space-3xl` (`6rem`) margins, emphasizing standalone portfolio artifacts.
- **Micro Spacing:** Internal card padding, diagnostic telemetry meters, and form inputs use `space-md` (`1rem`) to `space-lg` (`1.5rem`) to maintain structural density and data cohesion.
- **Rhythm Anchors:** Layout stacks align to an underlying 4px baseline matrix.

## Elevation & Depth

Visual hierarchy does not use drop shadows, which can muddy dark interfaces. Instead, depth is established through backlighting, selective atmospheric occlusion, and microscopic edge illumination.

### Tonal Stratification
- **Ground (`#090A0F`):** Deep ambient base canvas.
- **Layer 01 - Docked Surfaces (`#0D111A`):** Low-contrast resting state for page segments and code execution wrappers.
- **Layer 02 - Floating Glass (`#141926` with 80% opacity and 16px backdrop-blur):** Interactive portfolio cards, modal overlays, navigation arrays.
- **Layer 03 - Focus & Inspect (`#1D2436` with 90% opacity and 24px backdrop-blur):** Interactive model inspections and contextual flyouts.

### Photonic Edge & Luminous Shadow
- **Ambient Floor Glow:** Low-frequency radial gradients (`radial-gradient(circle at 50% 0%, rgba(139, 92, 246, 0.12), transparent 70%)`) placed underneath high-priority modules.
- **Whisper Stroke:** Static surfaces use an outer border stroke of `1px solid rgba(255, 255, 255, 0.07)`.
- **Active Radiant Border:** Active and hovered nodes use a dual-layer treatment:
  1. A multi-color gradient border (`linear-gradient(135deg, rgba(139, 92, 246, 0.5), rgba(56, 189, 248, 0.2))`).
  2. An ambient outer luminescence: `box-shadow: 0 0 30px -5px rgba(139, 92, 246, 0.25), 0 0 10px -2px rgba(56, 189, 248, 0.15)`.

## Shapes

The design uses a clean, architectural shape language: neither hyper-curved and toy-like, nor brutally sharp and dated.

### Curvature Tokens
- **Standard Controls & Elements (`rounded-md` - 0.5rem):** Applied to buttons, code-copy chips, form fields, and dropdown pills.
- **Panels & Display Cards (`rounded-lg` - 1rem):** Applied to AI project showcases, system monitors, neural architecture diagrams, and modal containers.
- **Hero Containers (`rounded-xl` - 1.5rem):** Applied to main hero media anchors, interactive WebGL canvases, and highlighted case studies.
- **Pill Geometry (`full`):** Reserved strictly for micro-status indicators (e.g., model training pulses, benchmark tags, system state indicators).

## Components

### Buttons
- **Primary Action (Compute Primary):**
  - Background: Linear blend `linear-gradient(135deg, #8B5CF6 0%, #7C3AED 100%)`.
  - Border: `1px solid rgba(255, 255, 255, 0.2)`.
  - Text: `#FFFFFF`, `Space Grotesk`, medium weight (`500`), letter-spacing: `0.02em`.
  - Hover: Ambient violet glow (`0 0 25px rgba(139, 92, 246, 0.45)`), scale transition `1.015`.
- **Secondary Action (Sub-System / Code Link):**
  - Background: Glass plate `rgba(20, 25, 38, 0.6)` with `12px` backdrop blur.
  - Border: `1px solid rgba(255, 255, 255, 0.1)`.
  - Text: `#F8FAFC`. Hover brings border to `rgba(56, 189, 248, 0.4)` with cyan micro-glow.
- **Ghost Action:**
  - Background: Transparent. Text: `#94A3B8`. Hover text transitions to `#F8FAFC` with an underline glow.

### Cards & Case Studies
- **Structure:** Encased in `rgba(13, 17, 26, 0.75)` with `16px` backdrop filter, framed by a `1px` subtle boundary (`rgba(255, 255, 255, 0.06)`).
- **Interactive State:** Hover initiates an animated radial spotlight tracking the cursor across the border using CSS variables (`--x`, `--y`), shifting edge opacity to electric purple (`#8B5CF6`).
- **Internal Modules:** Feature an integrated telemetry header displaying the model type, inference framework, and latency in `JetBrains Mono` (`label-mono`).

### Chips & Badges
- **Technical Badges:** Pill or slightly rounded containers (`rounded-md`, `0.375rem`).
- **Styling:** Semi-translucent dark tint (`rgba(139, 92, 246, 0.1)`), hairline border (`1px solid rgba(139, 92, 246, 0.25)`), text set in `JetBrains Mono` at `0.75rem` with uppercase styling.
- **Status Pills:** Include an active radial LED dot (e.g., `#38BDF8` with a 2-second subtle opacity pulse animation) signifying online APIs or production models.

### Input Fields & Search Bars
- **Surface:** `rgba(13, 17, 26, 0.9)`, border `1px solid rgba(255, 255, 255, 0.1)`.
- **Text:** Typed input in `Inter` (`#F8FAFC`); placeholders set in `#475569`.
- **Focus State:** Border shifts cleanly to `#8B5CF6` accompanied by an inner hairline glow (`box-shadow: inset 0 0 12px rgba(139, 92, 246, 0.15)`).

### Selection Controls (Checkbox & Radio)
- **Base:** Rounded rect (`4px`) for checkboxes; circular (`50%`) for radios. Background `#0D111A`, border `1px solid rgba(255, 255, 255, 0.2)`.
- **Selected State:** Filled with `#8B5CF6`, displaying a clean geometric white glyph. Micro-halo surrounding the control using `#8B5CF6` at 30% alpha.

### Code & Benchmark Inspection Blocks
- **Header:** Terminal bar styled with file tree markers, memory utilization metrics, and direct copy buttons.
- **Interior:** Obsidian void (`#06080C`) flanked by faint line counters (`#334155`). Code text rendered in `JetBrains Mono` (`code-inline`) with high-contrast pastel syntax highlighting (lavender for keywords, soft cyan for functions, slate for parameters).
